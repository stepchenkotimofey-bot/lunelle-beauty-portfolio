# Lunelle

Портфолио-концепт сайта для премиального салона красоты Lunelle.

## Структура

- `index.html` - разметка лендинга
- `styles.css` - адаптивный визуальный стиль
- `script.js` - мобильное меню, фильтр портфолио и форма записи
- `assets/lunelle-hero.png` - hero-изображение

## Локальный запуск

```bash
npx serve .
```
